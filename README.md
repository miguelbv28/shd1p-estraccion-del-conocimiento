## Objetivo del Proyecto
Desarrollar un repositorio académico en GitHub que integre los procesos de limpieza de datos, análisis estadístico descriptivo, visualización de datos, interpretación de resultados y la generación de conocimiento mediante el modelo DIKW (Datos, Información, Conocimiento, Sabiduría), utilizando un dataset público real.

---

## Datasets Utilizados
Dentro de la carpeta `Data/` se encuentran alojados los siguientes archivos de datos:
1. **Netflix.csv:** Contiene el registro de producciones, títulos, directores, países y métricas de la plataforma de streaming de Netflix.
2. **Amazon.data:** Contiene el registro de series, películas, géneros y calificaciones de usuarios de la plataforma Amazon Prime Video.

---

## Herramientas Utilizadas
Para el desarrollo de los análisis en este proyecto se utilizaron las siguientes herramientas tecnológicas en Python:
* **Pandas:** Para la manipulación, limpieza y estructuración de los datos.
* **NumPy:** Para soporte de vectores, matrices y funciones matemáticas.
* **Matplotlib / Seaborn:** Para la creación de gráficos estadísticos legibles y visualizaciones descriptivas.
* **Jupyter Notebooks:** Como entorno de desarrollo interactivo.
